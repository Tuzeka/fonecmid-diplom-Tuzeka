# Доработка «Управление IT-фирмой»: обслуживание клиентов и управленческая зарплата

Дипломный проект — доработка типовой конфигурации 1С:Предприятие «Управление IT-фирмой» для компании «Ваш компьютерный мастер» (все добавленные объекты — с префиксом `ВКМ_`). Добавлены два независимых блока:

- **Обслуживание клиентов** — заявки на визиты специалистов, привязка к абонентским договорам, автозаполнение актов, уведомления в Телеграм, календарь загрузки специалистов.
- **Расчёт управленческой зарплаты** — оклады, отпускные, проценты от выработки, премии, НДФЛ и взаиморасчёты с сотрудниками на механизме сложных периодических расчётов — теме экзамена «1С:Специалист».

## Структура репозитория

| Папка | Содержимое |
|---|---|
| `ConfigurationFonecmidDiplomTuzeka/` | исходники конфигурации в формате 1C:EDT |
| `VA_Test/` | автотесты Vanessa Automation (`.feature`) и инструкция по их запуску |
| `manual/` | инструкция по начальной настройке после внедрения |

## Функциональность

### Обслуживание клиентов

- Справочник **Сотрудники** (специалисты и административный персонал) и договоры контрагентов с видом «Абонентское обслуживание».
- Документ **Обслуживание клиента** — проводится только по действующему абонентскому договору и при заполненных условиях оплаты специалиста.
- Автозаполнение документа **Реализация товаров и услуг** и печатная форма **Акта** по итогам визитов за период.
- Обработка **Массовое создание актов** — формирует реализации по всем договорам за период в фоновом задании.
- Уведомления в Телеграм о новых и изменённых заявках (очередь в справочнике, регламентное задание на отправку).
- Обработка **Календарь специалистов** — загрузка специалистов на планировщике (drag-and-drop создание заявок).

### Расчёт управленческой зарплаты

- Механизм сложных периодических расчётов: 3 плана видов расчёта, 3 регистра расчёта, 2 объекта перерасчёта.
- Документ **График отпусков** — ввод отпусков, подсветка превышения 28 календарных дней, диаграмма Ганта, авторегистрация перерасчёта при изменении задним числом.
- Документ **Начисление зарплаты** — оклад (с вычетом отпускных дней), отпускные (по среднедневному заработку за 12 месяцев), процент от выполненных работ, НДФЛ через формальную базу.
- Документ **Начисление фиксированной премии** и документ **Выплата зарплаты** с автозаполнением по остаткам взаиморасчётов.

## Отчёты

| Отчёт | Источник данных |
|---|---|
| Выработка специалистов | регистр «Выполненные сотрудником работы» |
| Анализ выставленных актов | регистры «Выполненные клиенту работы» + «Продажи услуг» |
| Расчёты с сотрудниками | регистр «Взаиморасчёты с сотрудниками» |
| Расход запланированных отпусков | регистр «Запланированные отпуска» + регистр расчёта «Основные начисления» |

## Роли доступа

| Профиль | Назначение |
|---|---|
| Специалист | выполнение заявок на обслуживание |
| Менеджер | планирование заявок клиентам |
| БухгалтерИТФирмы | массовое создание актов, отчёт по актам |
| КадровикРасчетчик | весь блок расчёта зарплаты и зарплатные отчёты |

## Требования

- 1С:Предприятие, платформа 8.3.27 (или совместимая 8.3.x).
- Базовая конфигурация «Управление IT-фирмой» с БСП 3.1.9.199.
- Vanessa Automation 1.2.043.42 — для запуска автотестов.

## Установка и настройка

Порядок заполнения констант, назначения ролей пользователям и прочих действий перед вводом в эксплуатацию — в [`manual/Initial setup instructions.md`](manual/Initial%20setup%20instructions.md).

## Автотесты

Два сценария Vanessa Automation и инструкция по их запуску (окружение, привязка к датам, повторные прогоны) — в папке [`VA_Test/`](VA_Test/):

- `ВКМ_СквознойПроцессОбслуживания.feature` — планирование и закрытие заявок, массовое создание актов, сверка отчёта «Анализ выставленных актов» с эталоном.
- `ВКМ_ЗаявкиКлиентов.feature` — проведение заявки по действующему договору, отказ проведения вне периода договора, постановка уведомления в очередь Телеграм-бота.

## Известные ограничения

Присоединённые файлы к документу «Обслуживание клиента» — метаданные справочника присутствуют, но библиотека БСП «Присоединённые файлы» в базовой конфигурации «Управление IT-фирмой» не подключена (общих модулей для неё нет и у типового документа «Реализация товаров и услуг»). Это ограничение базовой конфигурации, не доработки.
